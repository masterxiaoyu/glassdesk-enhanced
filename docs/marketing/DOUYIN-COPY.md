## 发布正文

常用软件放 Dock，同类工具直接拖到一起收纳。
想用顶部菜单栏，就在设置里切换；喜欢 Windows 任务栏，也可以继续用。

这次把音量、电池、网络和日历拆成了独立面板，
Dock 大小、透明度、自动隐藏也都能自己调。
应用多了可以在启动台里搜，也能开启单击 Win 键切换窗口。

GlassDesk，免费，适用于 Windows 11 x64。
当前是预览版，下载前记得看版本说明。

GitHub：masterxiaoyu/glassdesk-enhanced
