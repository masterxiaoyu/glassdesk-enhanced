## 版本号与交付物

首个正式版本为 **1.5.0**。兼容修复使用 `1.5.x`，新增功能提升次版本
（例如 `1.6.0`），破坏兼容的变更提升主版本（例如 `2.0.0`）。
同一发布的程序、安装包、便携 ZIP、更新说明和 GitHub 标签使用一致版本；
Windows 文件版本使用四段数字，如 `1.5.0.0`。

正式发布至少提供安装 EXE、无用户数据的便携 ZIP、更新说明和 SHA-256。
安装 EXE 采用固定 AppId `GlassDesk.Independent` 与同一默认安装路径，
使后续版本在原位置覆盖升级。不得在公开安装包或 ZIP 中包含个人 `Data`、
日志、收款账号以外的私人资料或本机路径。

## 安装、升级与卸载的数据规则

`Data` 位于程序实际运行目录旁。覆盖升级时默认保留现有 `Data`；
安装界面允许用户明确选择删除旧 `Data`，未选择则不删除。卸载时也
默认保留 `Data`，并提供明确的删除选项。删除前提示该操作会移除
软件列表、分组、布局和设置，建议先备份。安装器不得从旧便携版目录
自动搜集或删除 `Data`。

发布前应在干净安装、同 AppId 覆盖升级、升级时保留/删除、卸载时
保留/删除各路径验证实际文件结果；仅编译通过不算安装验收。
若某次发布明确跳过某项实测，须在该版本更新说明中标明未验证，
不得把源码检查或安装器编译视作该路径已验收。
