# GlassDesk 1.6.0-preview.13

本次更新集中改进应用添加、菜单栏操作和后台资源释放。
这是预发布版本，支持 Windows 11 x64（Build 22000 及以上）。

## 应用添加与界面

- “从桌面批量添加”支持按名称或路径搜索，搜索前后保留已选项目。
  全选仅作用于当前结果，取消全选清除所有勾选。
- 修复桌面导入列表鼠标滚轮滚动，统一细滚动条。
  导入窗口使用深色背景，避免文字与启动台内容重叠。
- 调整设置窗口圆角；右键菜单显示开关勾选与子菜单箭头。

## 菜单栏与系统入口

- Windows 图标左键打开开始菜单，右键打开系统原生快捷菜单。
  终端、管理员入口和系统工具沿用当前 Windows 配置。
- 右键菜单栏中的 GlassDesk 名称或后台图标，可打开设置、管理开机自启、
  检测更新或查看关于。Dock 也保留这些入口。
- 菜单栏空白处及其他应用名称不再弹出 GlassDesk 产品菜单。
- “Dock → 菜单栏操作”新增音量图标滚轮调音量、
  双击空白处显示桌面，以及应用菜单显示开关。新增鼠标操作默认关闭。

## 全屏休眠与资源释放

- “游戏休眠”统一为“全屏休眠”，覆盖任意全屏应用；退出全屏后自动恢复。
  通过托盘手动启用的休眠仍需手动取消。
- 启动台隐藏后的页面与纹理保留时间由 30 秒缩短至 8 秒。
- 清理图标缓存时同时释放挂起的解码请求，减少对旧页面的引用。
- 合并后台图标刷新，内容未变时复用已有位图。
  休眠期间不重建隐藏的菜单栏图标，导入窗口不再重复采集玻璃背景。

## 下载与升级

- 安装版：`GlassDesk-1.6.0-preview.13-win-x64-Setup.exe`
- 便携版：`GlassDesk-1.6.0-preview.13-win-x64-portable.zip`
- 校验文件：`SHA256SUMS.txt`

包内已包含 .NET 运行环境。升级前退出 GlassDesk，并备份程序目录中的
`Data`；安装版默认保留现有设置和布局，不迁移其他便携目录的数据。
预览版请从本页下载安装；软件内自动更新目前仅检查正式版本。

## 验证范围与已知限制

- Release 构建无警告；相关 WPF 交互和图标资源生命周期回归已通过。
- 安装验收覆盖隔离标识下的首次安装、覆盖升级、数据保留和静默卸载；
  交互式清除数据路径及升级后完整桌面会话重启不在本次实测范围内。
- 挂起请求对照测试中，旧版清理后仍保留 96 个负载，新版最多保留
  工作线程已取出的 1 个。这是引用生命周期测试，不代表整机内存降幅。
- 尚未在低内存旧电脑、多种显卡和多显示器组合上完成性能测量。
- 完整系统通知同步仍未开放，包内不含实验通知组件或测试证书。
- 顶部应用菜单仅显示软件实际提供的菜单；自绘菜单应用仍需在其窗口操作。
- 安装程序尚未进行受信任的代码签名，请核对随包 SHA-256。
