# GlassDesk 1.6.0-preview.13

Windows 11 x64 桌面工具。软件免费，当前为预发布版本。

## 开始使用

运行 `GlassDesk.exe`，将常用软件拖入 Dock。
右键 Dock 选择“设置”，即可调整外观、大小和显示方式。

- 将应用拖到另一应用上方，停留后松手，可直接收纳；点击分组展开。
- 点击九宫格图标打开启动台，浏览或搜索应用。
- 在“Dock → 任务栏模式”选择 Windows 任务栏或 macOS 风格菜单栏。
- 顶部的网络、音量、电池、日期分别打开独立面板。
- 左键点击顶部 Windows 图标打开开始菜单；右键打开 Windows 原生
  快捷菜单，系统工具与管理员终端入口沿用当前 Windows 配置。
- 在“快捷操作”中按需启用单击 Win 键切换窗口。
- 启动台“添加 → 从桌面批量添加”支持按名称或路径搜索。
  “全选”只勾选当前搜索结果，清空搜索后仍保留已选项目。
- 在“Dock → 菜单栏操作”中设置应用菜单、滚轮音量与双击显示桌面。
- 右键菜单栏中的 GlassDesk 名称或后台图标，以及 Dock，可管理开机自启、
  检测更新或查看关于。菜单栏空白处不弹出产品菜单。
- 在“性能”中设置全屏休眠；开启后，任意应用全屏时自动收起桌面栏，
  退出全屏后恢复。托盘菜单也提供手动休眠。

完整系统通知同步暂未开放，本包不包含实验通知组件或测试证书。
使用其他功能无需安装证书。

## 更新和数据

安装版更新前先退出 GlassDesk，沿用原安装路径。
设置、应用库和布局位于程序目录的 `Data` 文件夹，默认保留。
建议更新前在“备份与恢复”中创建备份。
便携版需完整解压到可写文件夹，再运行程序。
正常退出 GlassDesk 后，Windows 任务栏会恢复显示。
