# GlassDesk 1.6.0-preview.9

- 底部 Dock 支持应用启动、固定、排序、叠放收纳及运行窗口切换。
- 在“设置 → Dock → 任务栏模式”选择 Windows 任务栏或 macOS 风格菜单栏。
- 顶部 Windows 图标打开开始菜单，日期按钮打开独立日历。
- 网络、音量、电池与通知使用独立面板；有线连接优先显示。
- 接通电源时电池显示闪电标记，电池供电时显示电量条。
- “•••”显示应用托盘图标，支持拖到菜单栏常驻及拖回收纳。
- 在“设置 → 快捷操作”启用单击 Win 键切换窗口。

完整系统通知需要安装通知组件并由用户授权，步骤见
[通知组件安装说明](INSTALL-NOTIFICATIONS.md)。

用户设置、应用库与布局保存在程序目录下的 `Data` 文件夹。
更新前请备份此文件夹；程序正常退出后恢复 Windows 任务栏。
预览版不自动迁移其他安装目录的数据。

请保留随附的许可文件与第三方声明。
