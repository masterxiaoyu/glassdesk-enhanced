# GlassDesk 1.6.0-preview.12

本地候选版，尚未发布到 GitHub。支持 Windows 11 x64。

- 使用 macOS 风格菜单栏时，右键 Windows 图标打开原生快捷菜单。
  系统工具、终端及管理员入口由当前 Windows 配置提供。
  左键仍打开开始菜单。
- 菜单栏空白处与 Dock 右键继续提供 GlassDesk 设置、开机自启、
  检测更新和关于入口。
- 包含上一候选版的导入搜索、滚轮修复、菜单栏操作设置与资源释放优化。

原生菜单通过 Windows 的 Win+X 系统入口调用，未复制菜单内容、
修改系统快捷菜单或变更 UAC 权限流程。
入口依据：[微软键盘快捷键文档](https://support.microsoft.com/en-gb/accessibility/windows/keyboard-shortcuts-in-windows)。

完整系统通知同步仍未开放，不包含实验通知组件或测试证书。
