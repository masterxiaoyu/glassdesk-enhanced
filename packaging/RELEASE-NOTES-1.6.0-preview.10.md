# GlassDesk 1.6.0-preview.10

本次更新集中整理了 Dock、顶部菜单栏和系统状态入口。
这是预发布版本，适合先体验并反馈使用问题。

## 新增与调整

- 底部悬浮 Dock 支持应用拖拽排序、直接叠放收纳与运行窗口切换。
- Windows 任务栏与 macOS 风格菜单栏可在设置中切换，使用一个统一模式。
- 顶部菜单栏提供网络、音量、电池、日历和控制中心的独立面板。
- 后台应用图标可拖入菜单栏常驻、调整顺序，也可拖回收纳。
- 有线与 Wi-Fi 使用同一个网络入口；有线连接优先显示。
- 电池接通电源时显示闪电标记，使用电池时显示电量条；充满后仍能区分供电来源。
- 可选单击 Win 键打开窗口切换界面，保留 Win+D、Win+E 等组合键。
- 调整启动台图标与设置文案，减少重复说明。

## 修复

- 补齐当前 Windows 外壳实际使用的音量、电源图标标识，
  避免原生图标与顶部独立入口重复。
- 修复托盘小图标裁切，调整图标尺寸与点击区域。
- Dock 过滤 Windows 输入体验窗口，不结束输入法进程。
- 切换任务栏模式、调整工作区和退出时恢复对应空间，减少界面反复跳动。

## 下载与更新

- 安装版：`GlassDesk-1.6.0-preview.10-win-x64-Setup.exe`
- 便携版：`GlassDesk-1.6.0-preview.10-win-x64-portable.zip`

需要 Windows 11 x64（Build 22000 及以上）。分发包已包含运行所需的
.NET 组件，无需另装 .NET 运行时。

更新前退出 GlassDesk，并备份程序目录下的 `Data`。
分发包不包含个人数据，不自动迁移其他便携版目录的数据。
安装器的数据保留与删除规则见随包发布政策。

## 当前范围

- 完整系统通知同步暂未开放。公开包不附带实验通知组件或测试证书，
  不要求用户为了使用 Dock、网络、音量、电池或日历去安装证书。
- 顶部应用菜单仅显示软件实际提供的菜单，不能为自绘菜单应用补出通用菜单。
- 不同 Windows 版本、显示缩放、显卡驱动和多显示器配置仍需持续验证。
- 自动回归 1,182 项通过；最终完整载荷在隔离安装标识下完成首次安装、覆盖升级和静默卸载，数据均保留，启动自检通过。
  交互式清除数据路径尚未实测；多显示器及不同硬件环境仍需验证。

安装包未进行受信任的代码签名，Windows 可能显示安全提示。
请从本仓库 Release 下载，并核对 SHA-256。
