# GlassDesk 1.6.0-preview.11

本地候选版，尚未发布到 GitHub。支持 Windows 11 x64。

## 界面与操作

- 桌面批量添加支持名称、路径搜索；保留跨搜索结果的勾选状态。
  全选仅作用于当前结果，取消全选清除所有勾选。
- 修复导入列表鼠标滚轮滚动，使用统一的细滚动条。
  导入面板改为静态深色背景，避免正文与启动台内容重叠。
- 设置窗口使用紧凑圆角；右键菜单显示勾选状态与子菜单箭头。
- 菜单栏新增可选操作：在音量图标上滚动调节音量、
  双击空白区域显示桌面，以及显示或隐藏当前应用菜单。
  新鼠标操作默认关闭，应用菜单沿用原来的显示状态。
- 菜单栏和 Dock 右键菜单提供开机自启、检测更新和关于入口。
  自启动状态直接读取系统登记；更新与关于复用现有设置页。
- “游戏休眠”统一为“全屏休眠”；自动检测范围包括任意全屏应用。
  退出全屏后自动恢复，手动休眠需通过托盘取消。

## 资源占用

- 清理图标缓存时同时完成并释放待处理请求，避免挂起队列继续引用旧页面。
- 启动台隐藏后的页面与纹理保留时间由 30 秒缩短为 8 秒。
- 菜单栏合并同一轮托盘更新；内容未变时复用现有图标位图。
  全屏休眠期间不重建隐藏的托盘图标。
- 桌面导入对话框不再重复启动玻璃背景采集。

## 验证范围

- Release 构建及相关 WPF 回归测试：搜索、勾选、滚轮、任务栏设置保存、
  图标加载、后台挂起与恢复、菜单栏图标拖放及既有设置页面。
- 用修改前启动台程序集对照同一组 96 个挂起请求：旧版清理后保留 96 个，
  新版最多保留工作线程已取出的 1 个；其余请求均完成并释放负载。
  这是合成请求的引用生命周期验证，不代表整机内存下降比例。
- 检查 600×560 和 420×320 导入窗口的实际 WPF 渲染。
- 尚未在低内存旧电脑上完成实机性能测量，不承诺固定内存或帧率。

## 设计参考

参考 [MyDockFinder](https://store.steampowered.com/app/1787090/MyDockFinder/)
和 [BitDock](https://bitdock.cn/) 的面板层级、间距与常用入口组织。
“7task++”本次按 [7+ Taskbar Tweaker](https://tweaker.ramensoftware.com/)
理解，借鉴滚轮、双击等可选操作的设置方式；未引入其任务栏注入组件。

完整系统通知同步仍未开放，本包不包含实验通知组件或测试证书。
