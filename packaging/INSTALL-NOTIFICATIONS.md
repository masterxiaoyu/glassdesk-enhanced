# GlassDesk 通知组件

此安装包为本地预览版。通知组件使用随附的测试证书签名，
安装程序不会自动修改 Windows 证书信任。

1. 退出正在运行的 GlassDesk。
2. 打开 `GlassDesk.Notification.Test.cer`，核对发布者为
   `CN=GlassDesk Preview`。选择“安装证书 → 当前用户”，
   将证书放入“受信任的人”证书存储。
3. 运行随附安装程序。已使用便携预览的用户也可在通知中心点击
   “安装通知组件…”，完成后重新启动 GlassDesk。
4. 点击顶部通知按钮，再点击“授权通知访问…”，在 Windows 提示中
   选择是否允许 GlassDesk 访问通知。

授权后，通知中心显示系统通知并支持单条清除。拒绝或撤销权限时，
面板显示授权状态，不读取通知内容。通知数据不写入本地日志或上传。

电池、音量、网络和日历功能不需要通知访问权限。
