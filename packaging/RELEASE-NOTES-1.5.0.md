# GlassDesk 1.5.0 更新说明（非官方修改版）

本版基于 everlosttime 的 GlassDesk 1.4.0 公开源码修改。
[原产品](https://github.com/everlosttime/glassdesk) ·
[原公开源码](https://github.com/everlosttime/glassdesk-open-source)。
这是独立维护的版本，并非原作者发布。

## 新增

- Dock 软件聚合工具栏：创建、编辑和删除自定义分组；从应用库选择
  软件或导入 `.exe`、`.lnk`，再从分组菜单启动。
- 设置中心显示系统任务栏位置、透明效果状态，提供系统任务栏自动
  隐藏开关及相关 Windows 设置入口。
- 软件内展示本版维护者的自愿赞助码；全部功能免费，赞助与原作者无关。

## 修复

- 修复软件聚合编辑窗口的文字和背景对比不足。
- 其他软件窗口覆盖 Dock 区域时，鼠标悬停不再唤出 Dock。

## 安装与已知边界

安装包和便携版的数据处理应遵循[发布政策](RELEASE-POLICY.md)：
覆盖升级默认保留 `Data`，删除需用户明确选择。已在隔离目录验证
干净安装、同 AppId 覆盖升级及安装时保留/清除测试 `Data`。
根据本次发布要求，卸载界面的保留/删除选项未做实际验收。

系统透明效果不会使任务栏完全透明；任务栏位置可选项取决于 Windows
版本。Dock 自动隐藏与 Windows 任务栏自动隐藏分别设置。

本版按现状提供。未签名安装包可能出现 Windows 安全提示；请从明确的
发布地址下载、核对 SHA-256，并在安装或升级前备份 `Data`。
分发时须保留 `LICENSE.txt`、`NOTICE.txt` 和第三方许可资料。
